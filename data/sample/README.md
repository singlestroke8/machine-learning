# サンプルデータ

`transactions_sample.csv` は、B2B 取引明細の**先頭1,000行**を切り出したものである。

**このデータは合成データであり、実在する企業・取引ではない。**
生成ロジックは `src/demand_forecast/data/transactions.py` にあり、
乱数シードを固定しているので誰が実行しても同じデータが得られる。

リポジトリを見た人が、実行しなくても中身を確認できるようにサンプルだけ追跡している。
全量（66,703行・11MB）は `.gitignore` の対象で、次のコマンドで再生成する。

```bash
uv run dfc generate-transactions   # → data/raw/transactions.csv
```

---

## 何のデータか

東京の1拠点から、関東近県の法人顧客に PC とソフトウェアを販売する会社の受注記録。
**1行 = 1回の受注に含まれる1品目**である（1回の受注で複数商品を買うと複数行になる）。

集計前の明細なので、ここから「部署別・商品別の日次販売数」などに集計して需要予測に使う。

## 列の説明

| 列 | 型 | 説明 |
| --- | --- | --- |
| 受注日 | 日付 | 受注が計上された日。**土日祝には発生しない**（法人取引のため） |
| 顧客コード | 文字列 | 顧客の識別子（C001 〜） |
| 顧客名 | 文字列 | 顧客企業名 |
| 顧客所在地 | 文字列 | 都県。関東近県の7都県のみ |
| 拠点 | 文字列 | 販売元。東京本社の1拠点のみ |
| 部署 | 文字列 | 営業1部 / 営業2部 / ソリューション営業部 |
| 営業担当者 | 文字列 | 顧客を担当する営業。**1顧客につき1名**で固定 |
| 品名 | 文字列 | 商材名（10種） |
| 品名カテゴリ | 文字列 | PC / ソフトウェア |
| 数量 | 整数 | 販売台数・ライセンス数 |
| 定価 | 整数 | 商材の標準価格（円） |
| 値引率 | 小数 | 定価からの値引き割合。`0.15` = 15%引き |
| 販売単価 | 整数 | `定価 × (1 - 値引率)`（円、10円単位に丸め） |
| 販売金額 | 整数 | `販売単価 × 数量`（円） |
| 原価単価 | 整数 | 1個あたりの仕入原価（円） |
| 原価 | 整数 | `原価単価 × 数量`（円） |
| 粗利 | 整数 | `販売金額 - 原価`（円）。**常に正**（原価割れの受注はしない） |

## サンプルの範囲

| 項目 | サンプル | 全量 |
| --- | --- | --- |
| 行数 | 1,000 | 66,703 |
| 期間 | 2022-01-04 〜 2022-01-21 | 2022-01-01 〜 2024-12-31 |
| 顧客数 | 80 | 80 |
| 営業担当者数 | 12 | 12 |
| 品名数 | 10 | 10 |
| 部署数 | 3 | 3 |

顧客・担当者・商品はすべて登場するが、**期間が3週間ぶんしかない**ため、
年度末の需要増などの季節変動はサンプルからは読み取れない。

## 全量データの特徴

| 項目 | 値 |
| --- | --- |
| 営業日数 | 733 日（全 1,096 日中） |
| 部署×品名の系列数 | 30 |
| 営業日のゼロ率 | 13.6% |
| 総販売金額 | 約 1,209 億円 |
| 平均粗利率 | 23.4% |
| PC の粗利率 / 値引率 | 11.0% / 0〜17% |
| ソフトウェアの粗利率 / 値引率 | 40.9% / 1.8〜35% |

## データに組み込んである業務上の性質

- 土日祝は受注ゼロ（営業日のみ）
- 年度末（3月）・半期末（9月）の予算消化による増加
- 期初（4月・10月）と夏季休暇（8月）の落ち込み
- 月末（25日以降）に締めの受注が寄る
- 部署ごとの得意商材（営業1部は PC 寄り、ソリューション営業部はソフトウェア寄り）
- 顧客ごとの値引き交渉力の差と、値引きに応じた数量の増加
- 値引きは粗利が確保できる範囲まで（ハードは値引き余地が小さく、ソフトは大きい）
- PC は薄利・ソフトウェアは高利益率という原価率の差

## 組み込んでいない性質（実データとの差分）

実データに差し替える際は、以下への対処が別途必要になる。

- 失注・キャンセル・返品（数量が負になる行）
- 顧客の新規獲得と取引終了（このデータでは期間中ずっと顧客が固定）
- 納期遅延による計上日のずれ
- 入力ミス・記録漏れなどのデータ品質問題
