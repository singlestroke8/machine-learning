## 書き方の方針

このリポジトリの説明は、次の原則で書いている。

1. **数式を使わない。** 必要なら図か具体例に置き換える
2. **専門用語には必ず言い換えを添える。** 「WAPE（在庫全体で何%外したか）」
3. **結論を先に書く。** 経緯は後
4. **できないことを明記する。** 過大な期待は後で信頼を損なう

4番目については、各ドキュメントに「できないこと」「言えないこと」の節を置いている。
現時点で最大の弱点は**予測の幅（区間）の当たり率が足りていない**ことで、
これは隠さずどのページにも書いてある。

## 前提の注意

**このリポジトリは練習用のデータで作っている。** 実際の取引記録ではない。

そのため精度の数字は「実務でこれが出る」という保証ではない。
何が作り物で、何が実際に分析して分かったことかは
[データについての注意](../data-understanding.md) に分けて記録している。
