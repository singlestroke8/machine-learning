# YYYY-MM-DD: （その日の主題を一行で）

## 今日やったこと

- 箇条書きで3〜5個。細かい作業ではなく「何が前に進んだか」を書く

## 学んだこと

その日に初めて理解したこと。「知った」ではなく「なぜそうなのか説明できるようになった」ことを書く。

### （見出しは学んだ内容ごとに）

- 何が分かったか
- なぜそうなるのか
- どこで使えるか

## 詰まったこと / 解決

**このセクションを最も厚く書く。**
うまくいったことは再現しにくいが、詰まりの記録は次に同じ壁に当たったときそのまま使える。

### 症状

何が起きたか。エラーメッセージがあればそのまま貼る。

### 原因

なぜ起きたか。「〜だと思う」で終わらせず、確認した方法まで書く。

### 対処

どう直したか。回避ではなく解決になっているかを自問する。

### 教訓

次に同じ状況になったとき、何を最初に疑うか。
