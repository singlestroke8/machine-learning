#

津軽三味線のバチの持ち方は、すべての演奏の土台になる一番の基本です。持ち方には色々な流儀があるようですが、ここでは 親指 → 人差し指・中指・薬指 → 小指 → 手首 の順に、それぞれの役割を解説します。なかでも「小指」には、 音色を左右する大きなポイント があると私は考えています。

目次

- 親指 ―― 弾いた瞬間に糸へ触れて音を整える

- 人差し指・中指・薬指 ―― バチをしっかり固定する

- 小指 ―― 音色と音量をコントロールする要

- 手首 ―― 角度で音の重さが変わる

津軽三味線のバチの持ち方（全体）

## 1. 親指 ―― 弾いた瞬間に糸へ触れて音を整える

まずは、バチを持つ手の親指の位置です。バチ先を1cmほど出し、指の半分を上にはみ出すように持ちます。この上にはみ出した指で、弾いた瞬間に糸へ触れることにより、 音色と音量をコントロール します。

親指の位置（バチ先を1cmほど出す）

## 2. 人差し指・中指・薬指 ―― バチをしっかり固定する

この3本の指は、バチが動かないようにしっかり握る役割をしています。ポイントは 「動かないように」 で、そのためにはちょっとしたコツがあります。

- この3本の指がそろってくっつかないように、軽く広げて使う

- 力の入れどころは中指と薬指の先で、バチが回転しないように意識する

- 人差し指は特に中指との間隔を保ち、バチが後ろにズレ下がるのを防ぐよう意識する

文章だけでは分かりにくいかもしれませんが、弾いているうちにバチが上手く持っていられない・ズレてしまう、という悩みは、この3本の指に原因があることが多いものです。ここの持ち方のコツを工夫することで、上手に持てるようになります。

## 3. 小指 ―― 音色と音量をコントロールする要

バチを持つ手の小指は、爪でコマ（駒）の下の方を押さえることで、 ボリュームと音色をコントロールする役割 があります。そのため、そもそもの前提として、コマの下の方を押さえられるような握り方をしていなければなりません。

### 小指で押さえるコマの場所

小指で押さえたり離したりするのは、コマの台座の部分です。コマには上から一の糸・二の糸・三の糸が張ってあり、その下にある台座を小指で押さえたり離したりすることで音をコントロールします。

小指でコマを押さえる位置

コマを押さえる小指の爪（○の部分）

なぜこのようなことをするのか。それは、これによってボリュームと音色をコントロールするためで、表現の幅を広げるための重要なテクニックだからです。

### 小指の使い方には2種類ある

小指の「使い方」には、大きく分けて2種類あります。それぞれに音色と音量の特徴があります。

#### 【1】小指を真っ直ぐに立てて、指先でコマを押さえる

- より小さな音になる

- 音色も細い印象になる

- 細かいコントロールはしにくいので、曲の中では“聞かせどころ”となる、ごく小さな音量が続くような部分に使う（いわゆる「音ずみ」とも言われる）

#### 【2】小指を軽く曲げて、爪の部分でコマを押さえる

- 音量は【1】ほど小さくはならないが、細かく「押さえる・離す」の繰り返しができる

- 離す瞬間の音色の変化を使える

- バチの動きの中で細かいコントロールができるので、前バチ⇔後バチの繰り返しサイクルの中で、前に来たときに小指を使い、後ろに下がったときに離す、という使い方ができる（前バチと後バチの強弱の効果をより強調するために、このテクニックは多用されます）

## 4. 手首 ―― 角度で音の重さが変わる

最後に手首です。バチを持った手でどのように糸を弾くか――まずは手首が重要です。右手（バチを持つ手）の手首は、内側に目一杯曲げます。曲げることにより手の重さがバチ先に伝わり、 重い音 が出ます。反対に手首が伸びていると、 軽い音 になります。

良い例：手首を内側に曲げている

良くない例：手首が伸びている

## おわりに

小指・親指のテクニックは難しいので、習い始めの方は最初からこれらを修得する必要はありません。

ただし、いずれ必ず必要になります。そのとき、それまで慣れた持ち方を全面的に変えるのはとても大変で、時間の無駄になってしまいます。ですから、 最初の段階でしっかりとした持ち方を覚えておく ことをおすすめします。
