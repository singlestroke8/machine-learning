# next-phase

`docs/PLAN.md` を上から読み、最初に `[ ]` が残っているフェーズを「現在のフェーズ」とする。

1. 現在のフェーズの目的・項目・完了条件を要約して示す。先のフェーズの作業は始めない。
2. 項目を上から順に実装する。1 項目終えるごとに `[ ]` を `[x]` に変える。
3. 完了条件を実際に実行して確認する（コマンドの出力を示す）。満たさない場合は「メモ」に理由を書き、止まる。
4. 完了条件を満たしたら `safe-commit` スキルの手順でコミットする。コミットメッセージは `Phase N: <フェーズ名>` で始める。
5. フェーズの順序は入れ替えない。項目の追加が必要なら、現在のフェーズの末尾に追記して理由をメモに残す。

TypeScript を書くときは、型の選び方・async/await・`for await` による SSE の読み方など、設計意図を短いコメントで添える。
Python のスクリプトは説明コメントを最小にする。
